# # Digital Forensic Investigation Report — Case AIT-DF-2026-009A digital forensics case study on deleted-data recovery from an NTFS disk image, produced as part of hands-on coursework covering digital forensics, file system analysis, and evidence handling.## OverviewThis report documents a simulated corporate case in which six directories were found missing from a workstation. The investigation traces the deletion, recovers the underlying data, and establishes a defensible timeline — following the same workflow used in real incident response and e-discovery engagements.**Case ID:** AIT-DF-2026-009**Evidence:** `Evidence.E01` (NTFS, Expert Witness / EnCase image format)**Investigator:** Erekosima Covenant## Objectives1. Determine the status of six target folders — `SSH`, `My pic`, `Our pic`, `ADDS Project`, `Corel`, `Corel Draw Work` — as Present, Deleted, Partially Deleted, Recoverable, or Unrecoverable.2. Maintain chain of custody and verify image integrity throughout.3. Establish a defensible deletion timeframe from filesystem artifacts.4. Recover evidence and calculate hashes for exported files.5. Cross-validate findings across multiple independent tools.## Tools Used| Tool | Purpose ||---|---|| `dd` | Bit-for-bit imaging and hash validation || R-Drive Image | Sector/partition structure verification || Exterro FTK Imager (v8.3.0.27) | MFT inspection, Recycle Bin and unallocated-space analysis || Autopsy (v4.23.1) | Deep MFT parsing, file carving, timeline reconstruction |## Methodology- Verified evidence integrity with SHA-256 and MD5 hashing before and after examination.- Inspected the NTFS `$MFT` root directory in FTK Imager to identify directories flagged as deleted.- Examined `$RECYCLE.BIN` for `$I`/`$R` index records to determine whether deletion bypassed the Recycle Bin.- Carved unallocated space in Autopsy to recover directories with no remaining MFT pointer.- Cross-referenced timestamps (`$STANDARD_INFO` modified/change/access) across tools to build a single defensible timeline.## Key Findings- **SSH**, **Corel**, and **corel draw work** were deleted directly from the MFT root and were fully recoverable via FTK Imager and Autopsy.- **My pic**, **Our pic**, and **ADDS Project** were deleted *and* unallocated from the MFT — recovery required file carving.- No Recycle Bin index records existed for any target folder, indicating deletion via Shift+Delete or a subsequent Recycle Bin purge.- Autopsy parsed **1,162 deleted file entries**; target assets (including `.cpt` graphics files) were successfully recovered.- The most defensible deletion window: **Sept 16, 2026, 11:01:30 WAT → Sept 24, 2026, 11:42:43 WAT**.## LimitationsDisk forensics alone cannot establish physical keyboard attribution or subjective intent — that requires secondary domain audit logs or physical security controls. Unallocated directory metadata also prevented direct path reconstruction for three of the six folders, requiring file carving instead.## Contents- `DIGITAL_FORENSIC_INVESTIGATION_REPORT_Erekosima_Covenant.pdf` — full report, including evidence tables, exhibit screenshots, the forensic timeline, and the chain-of-custody log.## DisclaimerThis is a training/practice exercise completed as part of coursework. The organization, case data, and evidence referenced are part of a simulated scenario and not an actual corporate incident.
